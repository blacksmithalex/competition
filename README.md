# Конкурс

Консольная программа на C++17 для регистрации участников, ввода баллов и подведения итогов конкурса.

## Структура проекта

```text
.
├── CMakeLists.txt              — конфигурация сборки CMake
├── README.md                   — описание проекта и инструкции
├── include/                    — заголовочные файлы
│   ├── Contest.h               — интерфейс и состояния конкурса
│   ├── Participant.h           — модель участника
│   └── Storage.h               — интерфейс файлового хранения
├── src/                        — исходный код программы
│   ├── Contest.cpp             — правила конкурса и определение призёров
│   ├── Storage.cpp             — чтение и запись текстовых файлов
│   └── main.cpp                — консольное меню и запуск программы
├── tests/
│   └── contest_tests.cpp       — автоматические тесты
└── report/                     — отчёт по курсовой работе
    ├── main.tex                — редактируемый TeX-исходник отчёта
    ├── main.pdf                — собранный итоговый отчёт
    ├── fonts/                  — шрифты для воспроизводимой сборки PDF
    └── listings/               — копии исходников, включённые в приложение
```

Папка `build/` создаётся CMake и содержит результаты сборки. Она не является частью исходного кода.

## Возможности

- до 1000 участников;
- от 1 до 10 призовых мест;
- уникальный положительный идентификатор участника;
- один итоговый балл от 0 до 100;
- сохранение незавершённой регистрации между запусками;
- сортировка результатов по убыванию баллов;
- расширение числа призёров при равенстве баллов на границе призовых мест;
- вывод результатов на экран и в файл `results.txt`.

## Сборка

Необходимы компилятор с поддержкой C++17 и CMake версии 3.16 или новее.

### Windows и Visual Studio

Откройте папку проекта в Visual Studio как проект CMake либо выполните в терминале разработчика:

```text
cmake -S . -B build
cmake --build build --config Release
```

Исполняемый файл будет находиться в `build/Release/contest.exe`.

### Linux и macOS

```text
cmake -S . -B build
cmake --build build
./build/contest
```

## Проверка

```text
ctest --test-dir build --output-on-failure
```

Тесты проверяют ограничения входных данных, запрет повторной регистрации идентификатора и балла, невозможность завершить конкурс без всех результатов и расширение списка призёров при равенстве баллов.

## Файлы данных

`participants.txt` создаётся рядом с программой при выходе во время регистрации. После окончательного завершения регистрации этот файл удаляется, так как ввод баллов и подведение итогов должны выполняться за один сеанс.

`results.txt` создаётся после завершения конкурса и содержит полный рейтинг с отметкой призёров.

## Отчёт по курсовой работе

Редактируемый отчёт находится в `report/main.tex`, готовая версия — в `report/main.pdf`. В титульном листе оставлены заполняемые поля для названия образовательной организации, кафедры, группы, ФИО студента и преподавателя, а также города.

Отчёт содержит техническое задание, обзор структур данных, описание архитектуры и алгоритмов, результаты тестирования, заключение, список источников и приложение с листингом программы.

Для самостоятельной сборки отчёта перейдите в каталог `report` и выполните:

```text
tectonic main.tex
```

Также можно использовать совместимый XeLaTeX-компилятор. Файлы из `report/fonts/` подключаются непосредственно из TeX-исходника. Каталог `report/listings/` содержит зафиксированные копии исходников, напечатанные в приложении отчёта. После изменения программы эти копии необходимо обновить перед повторной сборкой PDF.
