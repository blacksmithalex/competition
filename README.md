# Конкурс

Консольная программа на C++17 для регистрации участников, ввода баллов и подведения итогов конкурса.

## Возможности

- до 1000 участников;
- от 1 до 10 призовых мест;
- уникальный положительный идентификатор участника;
- один итоговый балл от 0 до 100;
- сохранение незавершённой регистрации между запусками;
- сортировка результатов по убыванию баллов;
- расширение числа призёров при равенстве баллов на границе призовых мест;
- вывод результатов на экран и в файл `results.txt`.

## Сборка

Необходимы компилятор с поддержкой C++17 и CMake версии 3.16 или новее.

### Windows и Visual Studio

Откройте папку проекта в Visual Studio как проект CMake либо выполните в терминале разработчика:

```text
cmake -S . -B build
cmake --build build --config Release
```

Исполняемый файл будет находиться в `build/Release/contest.exe`.

### Linux и macOS

```text
cmake -S . -B build
cmake --build build
./build/contest
```

## Проверка

```text
ctest --test-dir build --output-on-failure
```

## Файлы данных

`participants.txt` создаётся рядом с программой при выходе во время регистрации. После окончательного завершения регистрации этот файл удаляется, так как ввод баллов и подведение итогов должны выполняться за один сеанс.

`results.txt` создаётся после завершения конкурса и содержит полный рейтинг с отметкой призёров.
